# dragonruby-bunnymark
This is an implementation of the raylib bunnymark benchmark in the DragonRuby game development framework.  An example of the raylib version is available here:  https://www.raylib.com/examples/textures/loader.html?name=textures_bunnymark

## Installation
Navigate to the directory that contains your dragonruby executable and execute the following

```bash
git clone https://github.com/rebuilt/dragonruby-bunnymark.git mygame
```

## Run

```bash
./dragonruby
```
